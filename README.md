# Spartan Football Playbook Trainer

This folder is ready for GitHub Pages.

## Publish on GitHub Pages

1. Create a new GitHub repository, for example `spartan-playbook`.
2. Upload `index.html` from this folder to the root of the repository.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide a public website link.

The exact same app is also provided separately as:

`Spartan_Football_Playbook_Trainer.html`

That file can be downloaded and double-clicked on a Windows computer to run locally.

## Notes

- Studying, quizzes, route overlays, and run overlays work offline in the desktop HTML file.
- iPhone should use the GitHub Pages website link so Safari executes the JavaScript correctly.
- Score submission requires an internet connection because it sends results to the configured Google Apps Script endpoint.
